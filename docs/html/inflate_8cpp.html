Detailed Description

Minimal pure-C++ DEFLATE decoder.

Implements RFC 1951 — three block types: stored (00), fixed Huffman (01), dynamic Huffman (10). Pattern follows Mark Adler's "puff" reference implementation but adapted for std::vector output.
