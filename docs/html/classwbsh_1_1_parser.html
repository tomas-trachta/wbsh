Detailed Description

Parses a token stream into the wbsh AST.

Construct with a token vector (terminated by an EndOfInput token, as produced by Lexer::tokenize). Optionally pass the original source string so AST nodes can later be sliced out of it. Errors are accumulated; parsing continues best-effort.
